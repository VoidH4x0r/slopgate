# Held-out AI regression set

This is a fixed, independent prompt-style regression set. It was written from a separate prompt list after the main AI corpus was frozen, so it is closer to a held-out check than the development corpus. It is still synthetic and is not a representative sample of model output.

All high findings are labeled in `benchmark/heldout-labels.json`. Do not tune rules against these files without recording the change as a new corpus.
