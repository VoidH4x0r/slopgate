# Provenance

Generated for the 0.2.1 benchmark from a fixed prompt set asking for short
Python and TypeScript service/UI/test snippets in a "finish this feature"
style. The outputs were committed unchanged except for whitespace formatting;
all high-confidence findings were reviewed and labeled by hand.

- Date: 2026-11-22
- Generator: coding-agent model in the slopgate development session
- Prompts: the fixed templates in `PROMPTS.md`, one prompt per file, requesting
  a small realistic module and, where applicable, a matching test
- License: same as this repository (MIT)

The corpus is intentionally small and adversarial. It is a regression corpus,
not a statistically representative sample. Other models, prompts and
languages will produce different shapes.
